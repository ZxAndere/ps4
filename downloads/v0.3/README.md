El ZIP completo incluye código, informes, pruebas, fotogramas canónicos y referencias anteriores.
No se ha ejecutado el PKG/PRX en PS4 ni los EXE en Windows. No se acredita firmware 13.52,
GoldHEN «beta 12», aceleración GPU ni funcionamiento en juegos externos.

Los archivos son copias byte por byte de la entrega verificada. Se publican en Git porque
la API de GitHub Releases no está accesible desde este entorno.
