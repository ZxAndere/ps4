# PS4 Direct PKG - native probe

Independent from NovaPS. Experimental PS4 source: attempts to show a dialog; if /data/ps4direct_url.txt exists, probes a 1024-byte HTTP Range from the PS4 directly.

**This is NOT the finished downloader or installer.** It does not install packages, and must be tested on actual PS4 hardware. No certificate-validation bypass is included.

Github Actions should attempt to produce an actual PS4 PKG. Packaging success does not imply device compatibility.
